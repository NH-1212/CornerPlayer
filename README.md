# CornerPlayer

画面の角に小型のメディア表示を置く Windows 用アプリ。
他のアプリで再生中の曲情報を表示する表示専用。マウス入力を一切受け付けず、ゲーム中のフォーカスを奪わない設計。

## 機能

| 項目 | 内容 |
|---|---|
| 表示 | ジャケット画像、曲名、アーティスト名、プログレスバー、経過時間 / 総時間 |
| 曲名・アーティスト名 | 幅に収まらない場合のみ横スクロール（停止1.5秒 → 約40px/秒で移動 → 繰り返し） |
| 配置 | 四隅（左上・右上・左下・右下）をトレイメニューで選択。位置は保存される |
| 常に最前面 | 他のウィンドウが前面に来た場合のみ、1.5秒間隔のチェックで最前面を再設定 |
| 不透明度 | 100% / 80% / 60% / 40% |
| 多重起動防止 | 2つ目の起動は無視される |

ボタン・ドラッグ等のマウス操作は存在しない。再生操作はホットキーのみ。

## 対応する再生元

Windows のシステムメディアセッション（SMTC）に登録されたアプリが対象。
Spotify、ブラウザ（Chrome / Edge など）、Windows のメディアプレーヤー等。
表示できる範囲（ジャケット、再生位置等）は再生元アプリの対応状況による。
複数のアプリが再生中の場合は、Windows が「現在のセッション」とみなしたものを表示する。

| 項目 | 内容 |

## ビルド

1. .NET 8 SDK をインストール
2. zip を空のフォルダに展開する（既存フォルダへの上書き・二重展開はしない）
3. `CornerPlayer.csproj` があるフォルダで `build.bat` を実行（下記コマンドと同等）
4. `publish\CornerPlayer.exe` を起動

```
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

`CornerPlayer.csproj` は同フォルダ直下の `Program.cs` のみをコンパイルする。サブフォルダ内の `.cs` は対象外。

## 使い方

- 起動すると右下に表示され、タスクトレイにアイコンが入る
- 位置の変更・不透明度・終了はタスクトレイのアイコンを右クリックして行う

### ホットキー（グローバル）

| キー | 動作 |
|---|---|
| Ctrl + Alt + P | 再生 / 一時停止 |
| Ctrl + Alt + ← | 前の曲 |
| Ctrl + Alt + → | 次の曲 |
| Ctrl + Alt + H | 表示 / 非表示の切り替え |

- 他のアプリが同じキーを使用中の場合、そのホットキーは無効になる
- 上記の組み合わせを押している間、そのキー入力はゲームには届かない

### タスクトレイ

| 操作 | 動作 |
|---|---|
| 左クリック | 表示 / 非表示の切り替え |
| 右クリック | 左上 / 右上 / 左下 / 右下、不透明度、表示/非表示、終了 |

トレイ操作ではWindowsのシェルまたはメニュー表示用ウィンドウがフォアグラウンドになるため、ゲーム中は使用しない。
ゲーム中の表示切り替えは Ctrl + Alt + H を使う。

## フォーカスを奪わない仕組み

- `WS_EX_NOACTIVATE` を設定し、ウィンドウがアクティブ化されない
- `WS_EX_TRANSPARENT` + `WM_NCHITTEST` で `HTTRANSPARENT` を返し、マウス入力が常にウィンドウの背面へ通る
- `WM_MOUSEACTIVATE` に `MA_NOACTIVATE` を返す
- `WS_EX_TOOLWINDOW` によりタスクバー・Alt+Tab に表示しない
- ウィンドウ内にクリック可能・フォーカス可能な要素を持たない
- マウスフック・マウスキャプチャは使用しない
- 最前面の再設定は `SWP_NOACTIVATE` 付きで行う

## 設定ファイル

`%APPDATA%\CornerPlayer\config.json`（メニュー操作時に自動保存）

| キー | 既定値 | 内容 |
|---|---|---|
| Corner | `BottomRight` | `TopLeft` / `TopRight` / `BottomLeft` / `BottomRight` / `Custom` |
| X, Y | 0 | `Corner` を `Custom` にした場合の表示位置（DIP）。ファイルを直接編集して指定 |
| Margin | 12 | 四隅配置時の画面端との余白 |
| Opacity | 0.9 | 不透明度（0〜1） |

編集はアプリ終了中に行う。設定を初期化する場合はこのファイルを削除する。

## 制限事項

- 排他的フルスクリーンのゲームには表示できない。ボーダーレスウィンドウまたはウィンドウモードで使用する
- 四隅の配置はプライマリモニタの画面全体が基準（タスクバーと重なる場合は別の隅または `Custom` を使用）
- 再生元アプリがジャケット・再生位置を提供しない場合、プレースホルダまたは `--:--` を表示する
- アンチチート搭載ゲームとの互換性は未検証
- 作成時点でビルド・実機での動作確認は未実施
